# Overview

The Knowledge Graph is the intelligence backbone of TestDNA-AI.

While the **DNA Engine** extracts intelligence from individual automation assets, the Knowledge Graph connects those assets into a living network of engineering knowledge.

Without a Knowledge Graph:

```

```

remain isolated.

With a Knowledge Graph:

Every artifact becomes part of a connected intelligence network.

# Why a Knowledge Graph?

Enterprise engineering knowledge is highly connected.

A single test is related to:

- Requirements
- User stories
- APIs
- UI components
- Databases
- Feature flags
- Page Objects
- Executions
- Failures
- Developers
- Pull requests
- Releases

Traditional relational databases struggle to answer relationship-heavy questions.

Examples:

- Which requirements depend on this API?
- Which Page Objects are reused across projects?
- Which failures originated from this locator?
- Which business flows are affected by this commit?

A graph database answers these naturally.

# Graph Traversal

One of the biggest advantages of Neo4j is efficient graph traversal.

Example query:

> "Which checkout tests will break if Payment API changes?"

Traversal:

```
Payment API

↓

Called By

↓

CheckoutPage

↓

Used By

↓

Checkout Tests

↓

Executed In

↓

Regression Suite
```

Instead of scanning repositories, TestDNA-AI follows graph relationships.

---

# AI-Powered Relationships

Some relationships do not exist in source code.

Example:

Two tests may never import each other, but both validate the same business capability.

The AI creates a semantic relationship:

```
Test A

SIMILAR_TO

Test B

Confidence: 97%
```

This enables reuse recommendations that keyword search would miss.

# Graph + Vector Search

The Knowledge Graph works together with the Vector Database.

- **Graph** answers: *How are things connected?*
- **Vector Search** answers: *What is semantically similar?*

Example:

User asks:

> "Show tests similar to checkout validation."

Workflow:

1. Vector search finds semantically similar tests.
2. Knowledge Graph expands related APIs, Page Objects, and business flows.
3. AI ranks results by reuse score, stability, and confidence.

This hybrid approach delivers context-rich recommendations rather than simple search results.
